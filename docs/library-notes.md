# Library Notes

## Local Custom Libraries (stored in this repo)

These are self-contained and will resolve without any external tooling.

### `jackboys.kicad_sym`

- **KiCad library name:** `jackboys`
- **Registered in:** `sym-lib-table` → `${KIPRJMOD}/jackboys.kicad_sym`
- **Contains:** `MCP9600-E_MX` symbol only
- **Backup:** `jackboys.bak` (identical content, auto-generated by KiCad)
- **Created by:** Team (pyson2k, initial upload July 19, 2025)
- **Pins defined:** 30 (VIN+, VIN-, SCL, SDA, ADDR, VDD, GND×multiple, ALERT_1–4, EXP pads)

### `jackboys2.pretty/`

- **KiCad library name:** `jackboys2`
- **Registered in:** `fp-lib-table` → `${KIPRJMOD}/jackboys2.pretty`
- **Contains:** `QFN65P500X500X100-21N_MCP9600-E_MX.kicad_mod`
- **Footprint naming decoded:**
  - `QFN` — Quad Flat No-lead package
  - `65P` — 0.65mm pad pitch
  - `500X500` — 5.00mm × 5.00mm body
  - `X100` — 1.0mm height
  - `21N` — 21 electrical signal pad count
- **Pad structure:** 20 peripheral signal pads + 1 large exposed thermal pad (pad 21) with 9 thermal via pads (pads 22–30) inside it. Total 30 pads.
- **Standard KiCad QFN-20 was not used** — the MCP9600's exposed thermal pad required a custom variant.

## External Libraries (NOT in repo — must be reinstalled)

### `BMP581:BMP581`

- **Used by:** U2 in `thermometer.kicad_sch` (both symbol and footprint)
- **Source:** SnapEDA
- **SnapEDA part URL:** https://www.snapeda.com/parts/BMP581/Bosch/view-part/
- **SnapEDA PROD_ID:** IC-16798

**To restore (recommended: localize into repo):**

1. Download the KiCad format package from SnapEDA (`.kicad_sym` + `.kicad_mod`)
2. Place files in the repo:
   ```
   BMP581.kicad_sym
   BMP581.pretty/
   └── BMP581.kicad_mod
   ```
3. Add to `sym-lib-table`:
   ```
   (lib (name "BMP581")(type "KiCad")(uri "${KIPRJMOD}/BMP581.kicad_sym")(options "")(descr ""))
   ```
4. Add to `fp-lib-table`:
   ```
   (lib (name "BMP581")(type "KiCad")(uri "${KIPRJMOD}/BMP581.pretty")(options "")(descr ""))
   ```
5. Commit both files and the updated library tables to the repo.

Localizing prevents future broken-reference issues if SnapEDA updates or removes the part.
